# The shell (Quickshell)

Everything on screen that isn't an app window is one Quickshell config in
`.config/quickshell/`. It reloads itself whenever a file changes.

```
shell.qml      the root: creates every module once
theme/         Style.qml (sizes, font, text scale) · Icons.qml (Nerd Font glyphs)
               Colors.qml (generated by matugen, not in git)
services/      singletons that read the system: no UI
modules/       the UI: bar, popups, launcher, desktop, lock screen, ...
shaders/       GLSL sources + compiled .qsb for the living core
```

## Design

- **Services read, modules show.** A service is a singleton (`pragma Singleton`)
  that owns one source of truth (CPU, battery, notifications...). Modules only bind
  to service properties. Several modules can show the same data without reading
  it twice.
- **No fake values.** A service keeps `-1`, `""` or `ok: false` until real data
  arrives; the UI shows `--`.
- **Sampling, not polling everything.** System data is read every 2 s
  (`/proc`, `/sys`); slow things less often (weather 15 min, updates hourly).
- **One overlay at a time.** `Panels.open` names the open overlay or popup; opening
  one closes the other.

## Services

| Service | Provides |
|---|---|
| `Sys` | CPU (total + per core + history), memory, swap, network rates + history, temperature, uptime; every 2 s from `/proc` |
| `Disk` | local drives (`df`, one per device) and disk read/write rates (`/proc/diskstats`) |
| `Sensors` | Intel GPU busy share (RC6 residency, no root) and NVMe temperature |
| `Procs` | the busiest processes, sampled only while the dashboard's system tab shows |
| `AppIcons` | which apps have a single-color YAMIS icon |
| `Battery` · `BatteryLog` | UPower state and warnings · a 5-minute level history in `~/.local/state/battery-history` |
| `Power` | power profile and session actions |
| `Audio` · `Brightness` | default speaker volume/mute · screen brightness |
| `Wifi` | NetworkManager via `nmcli`: radio, network, signal, nearby networks, IP |
| `Privacy` | microphone and camera/screen capture in use (PipeWire streams) |
| `Media` · `Album` · `Lyrics` | what's playing (MPRIS) · its cover colors · synced lyrics from LRCLIB |
| `Visualizer` | cava's spectrum (20 Hz–20 kHz), bass/mid/high bands, beats |
| `Notifs` | the notification daemon: popups, history, do-not-disturb, unread count |
| `Hypr` | workspaces, focused window, focus/move helpers |
| `Panels` | which overlay is open, which quick-settings section is unfolded; most IPC targets |
| `Keymap` | keybinds and the leader menu, read from `keymap.lua` |
| `Apps` · `Actions` · `Calc` · `Files` · `Places` · `YouTube` · `Clipboard` | the launcher's sources |
| `Wall` | wallpaper path, folder, and setting one (runs matugen) |
| `Weather` · `WorldClock` · `Clock` · `Sunset` | Open-Meteo forecast · city times from tzdata · the time · night light |
| `Session` · `TextSize` · `Term` · `Updates` | stay-awake and lock state · one text size for shell/GTK/Ghostty · Ghostty windows · `checkupdates` count |

## Modules

| Module | What it is |
|---|---|
| `Bar` | one bar, two sides; framed blocks (logo, status, clock, power) open their panels; workspace squares with live hover previews; tray buttons |
| `TrayMenu` | a tray app's own menu, drawn in the shell's style |
| `QuickPanel` | quick settings: toggles and foldable sections (`Super + A`, status block) |
| `Dashboard` | overview, media, system and weather tabs (`Super + I`, clock block) |
| `Notifications` | the card stack: notifications (inline reply), now playing, levels |
| `Launcher` | the search box (`Super + Space`, `Super + V`), hanging from the left corner |
| `Overview` | workspaces with live window previews (`Super + Tab`) |
| `Cheatsheet` | keybind cheatsheet and leader menu |
| `PowerMenu` `WallpaperPicker` `Lock` | power menu (incl. reboot to UEFI), wallpaper picker, lock screen |
| `Wallpaper` `Desktop` `LivingCore` `MirrorWave` | the background, the desktop widgets, the creature, a mirrored bar graph |
| `AppIcon` | an app icon: YAMIS in the exact accent (a tint shader), else the regular icon |
| `Mono` `MonoButton` `Slider` | small building blocks in the shared style |

## IPC

The keybinds talk to the shell with `qs ipc call <target> <function>`:

| Target | Functions |
|---|---|
| `launcher` | `toggle`, `clipboard` |
| `keys` | `cheatsheet`, `leader` |
| `overview` · `quick` · `dash` · `power` · `picker` | `toggle` |
| `lock` | `lock`, `isLocked` |
| `notifs` | `clear`, `dnd` |
| `wallpaper` | `set <path>`, `next`, `get` |
| `textsize` | `set <scale>` (e.g. `1.15`), `step <1 or -1>` |
| `brightness` | `refresh` |

List them live with `qs ipc show`.

## Adding things

- **A keybind:** add a `bind(...)` line to `.config/hypr/config/keymap.lua`, then
  `hyprctl reload`. The cheatsheet picks it up by itself. Regenerate the docs page
  with `lua docs/keybinds.lua > docs/keybinds.md`.
- **A launcher action:** add an entry to `services/Actions.qml`
  (`name`, `glyph`, `keywords`, optional `confirm`, `run`).
- **An icon:** add a property to `theme/Icons.qml` with the codepoint from Nerd Fonts'
  `glyphnames.json` (never guess codepoints).
- **A new data source:** a new singleton in `services/`, sampled with a `Process` +
  `Timer`, exposing `-1` until real data exists.

## Checking a change

```sh
qs log | grep -iE "error|warn" | tail -20
```

`qs log` shows the running instance's output; the shell reloads on save, so errors
appear there right away.
